# Tile icons

`https://cdn.jsdelivr.net/gh/fl0zan0/savant_audio_proxy@main/icons/<file>`

| File | Use | Source |
|---|---|---|
| `radio.png` | radios tile (default) | Material Icons "radio" (Google, Apache-2.0), white, padded |
| `radio-france.png` | radios tile (optional) | Simple Icons "Radio France" via dashboardicons.com, white, padded |
| `music-assistant.png` | Music Assistant tile (default) | [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons) (Apache-2.0) |
| `roon.png` | Roon tile (default) | [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons) (Apache-2.0) |

Logos and brand names belong to their owners; they are only used to label the tiles.
